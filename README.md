# 그리기 연구실 02 · 머리카락 편 — 같은 얼굴, 다른 머리

연구실에 가발 상자가 도착했습니다. 하루·시아·모아·박사가 **가발로 변장**하며, 머리카락을 그리는 원리(이마 선·가르마·부피, 다발과 묶은 점, 흑백의 색과 윤기, 바람·늦게 따라오기·젖은 머리·감정)를 직접 움직이는 실험으로 익히고, AI 머리 문장·가림 영역·VFX 가이드 가닥으로 옮겨 봅니다.

**사이트:** https://adminmrobo.github.io/drawing_lab_02/
**앞 시리즈:** [구조 먼저 보는 캐릭터 그리기 연구실](https://adminmrobo.github.io/adminmrobo-structure_first_drawing_lab/) · [옷장 편](https://adminmrobo.github.io/structure_first_drawing_lab_01/) · [기분 편](https://adminmrobo.github.io/drawing_lab_01/)

## 등장인물과 변장
| 역할 | 캐릭터 |
|---|---|
| 모델 | 조수 하루(1부 짧은 단발 가발·4부 긴 웨이브 가발), 인턴1 시아(2부 자기 흑발 + 포니테일·말린·땋은 가발), 인턴2 모아(3부 금발·붉은·은발·흑발 가발), 5부는 셋 모두 |
| 손님 모델 | 박사(3부 흰머리 가발, 4부 쓸어 올린 앞머리·젖은 머리) |
| 화가 | 주판봇(바깥 윤곽부터·한 올씩 서두름), 초파리 연구원(머리 원형과 원리부터 의심) |
| 평가단 | X1 닮음(분홍 사이드 포니테일, 첫인상파) · X2 원리(베레모·청록 안경, 이마 선부터 따짐) · X3 자연스러움(고양이 귀 후드·노란 방울, 움직임에 예민) |
| 해설 | 박사 |

가발은 머리 모양만 바꿉니다. 얼굴·눈 색·옷·나이는 원래 캐릭터 그대로이며, 모두 20대 성인 연구원입니다(박사는 성인 남성).

## 구성
| 부 | 페이지 | 다루는 것 |
|---|---|---|
| 목차 | `index.html` | 세 줄 요약, 읽는 순서와 시간, 편 목록, 전체 흐름, 등장인물, 원리와 출처 |
| 1부 | `01_hair_frame.html` | 이마 선·가르마, 부피(실루엣 폭 = 머리 폭 + 2 × 두께), 길이와 끝 방향, 그리는 순서 |
| 2부 | `02_hair_bundles.html` | 다발(선 수 = 다발 × 속 선), 몸에 닿는 곳, 묶은 점, 말린 머리 원기둥(√(둘레² + 높이²))·땋은 머리 |
| 3부 | `03_hair_color.html` | 회색 농도(0.299R + 0.587G + 0.114B), 윤기 띠((빛 + 눈) ÷ 2), 밝은 머리, 검은 머리 윤기 비율 |
| 4부 | `04_hair_motion.html` | 바람(힘 ∝ 풍속²), 늦게 따라오기(거리 ÷ 빠르기 × 24장), 손과 물, 감정 과장 |
| 5부 | `05_ai_vfx.html` | 머리 문장 여덟 조각, 머리만 가려 다시 그리기, 가이드 가닥 × 채우기, 화풍별 다발 수 |
| 6부 | `06_failure_lab.html` | 진단 순서 + 머리카락 그림 실패 8종 + 머리 이름이 나이를 바꾸는 현상 |
| 7부 | `practice/index.html` | 실전 연습장: 미용실·바람 터널·머리 문장 공방·진단 데스크 |

1~6부 끝에는 **프롬프트로 직접 만들어 보기**와 **프롬프트 연습 문제**(부마다 2개, 상황·순서별 설명·연습 프롬프트·예상 결과·확인표·자주 나오는 실수)가 있습니다. 이 페이지 그림을 만드는 프롬프트(A)와 원리를 빼거나 바꾼 비교 문장(B), 결과 확인표, 참고 그림(`assets/refs/`) 내려받기를 담았습니다.

모든 실험은 외부 라이브러리 없이 동작하며, 그림 파일이 없어도 페이지가 완성 상태입니다.

## 그림
- 그림 37장(표지 8 + 본문 21 + 실패 8)은 Genspark로 만들어 반영했습니다(2026-11-24). 요청문: `docs/image_requests/` (저장 이름은 `checklist.csv`).
- 비교 그림(B 결과) 11장도 반영했습니다. 요청문: `docs/image_requests_make/`
- 연습 문제 예상 결과 그림 12장 요청문: `docs/image_requests_ex/` (`python3 build/make_requests_ex.py`) — 그림이 오기 전에는 '그림 준비 중' 자리입니다.
- 그림이 오면 `assets/img/{이름}.webp`로 넣고 `python3 build/build.py`, 표지는 `python3 build/make_og.py`까지 다시 돌립니다.
- 표지는 16비트 RPG풍 픽셀아트, 본문은 애니풍(3부 4단계는 흑백 만화풍, 5부 4단계만 네 화풍). 실사풍은 캐릭터를 코스프레한 가상의 성인 모델입니다.

## 원리와 출처
1~4부의 원리는 スタジオ・ハードデラックス 『デジタルツールで描く！感情があふれ出るキャラの表情の描き方』(マイナビ, 2015) 4장 특별편 「髪の描き方」 p.135~158을 참고했습니다. 책의 그림·문장·도식·구성 순서는 옮기지 않았고, 연구실 캐릭터와 직접 움직이는 실험으로 새로 구성했습니다. 교복·맨몸 습작 예시는 쓰지 않았습니다. 수식·기법 출처(ITU-R BT.601, Marschner 외 2003, Kajiya·Kay 1989, Jakobsen 2001, RePaint 2022, 잠재 확산 모델 2022)는 각 페이지 바닥글에 있습니다.
