**방법:** 둘 다 1차 결과를 첨부하지 말고, 새 대화에서 처음부터 만든다(1차 결과를 고치는 방식으로는 차이가 나지 않았음).

**Genspark에 먼저 붙여 넣기 ↓**
```
해설 페이지 본문에 넣을 그림을 한 장씩 차례로 만들어 줘.
- 비율은 각 프롬프트 첫 줄을 따를 것(16:9는 가로 1920px 이상, 2:3은 세로 1536px 이상)
- 첨부한 참고 이미지의 캐릭터 얼굴·눈 색·옷을 똑같이 지킬 것. 이번 편은 '가발로 변장'이라 머리 모양만 프롬프트대로 바꿈
- 등장인물은 모두 20대 성인(박사는 성인 남성). 노출·과장된 체형·교복 느낌 금지
- 그림 안에 글자·숫자·로고·말풍선 금지, 유명 애니 캐릭터와 닮으면 다시 만들 것

```
